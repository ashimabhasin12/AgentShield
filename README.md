# AgentShield

Human-defined security policies for autonomous AI agents.

## Research Objective

Evaluate declarative runtime security policies against
indirect prompt injection while preserving legitimate
task completion.

## Core Features

- Declarative knowledge representation
- Default-deny policy enforcement
- Task-scoped authorization
- Human approval mechanisms
- Security audit logging
- AgentDojo benchmark integration

## Technologies

- Python
- AgentDojo v1.2.2
- Ollama
- Groq
- GPT-OSS-20B
- JSON security policies

## Research Status

Preliminary experimental evaluation is ongoing.
Comparisons include baseline, safety instructions,
repeat user prompt and tool filtering.

## Limitations

Small experimental sample, API rate limits and
simulated human approval. Security superiority
has not yet been established.
