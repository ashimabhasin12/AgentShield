Declarative runtime authorization for autonomous AI agents

AgentShield investigates whether human-defined security knowledge can constrain indirect prompt injection while preserving legitimate task completion.

01 / Research overview

Security beyond instructions

Autonomous language-model agents interact with external tools and potentially untrusted data. Natural-language instructions alone may not reliably prevent unauthorized tool calls. AgentShield introduces an external, deterministic authorization layer that evaluates proposed actions using declarative security rules and task-specific permissions before dispatch. Preliminary experiments in the AgentDojo workspace suite examine utility and attack success across two model sizes and multiple defenses.

Can human-defined declarative security policies reduce indirect prompt injection attack success while preserving legitimate task completion?

Knowledge representation

Structured policies describe tools, resources, sensitivity, destinations and task scope.

Runtime enforcement

Default-deny decisions are made outside the language model before dispatch.

Empirical evaluation

Interactive benchmark utility and security checks, rather than static scenario classification.

Installation and recorded environment

Clone the repository with authorized access. Use an isolated Python environment; the dependency snapshot reflects the verification environment. Configure the inference provider locally without committing credentials.

git clone https://github.com/ashimabhasin12/AgentShield.git
cd AgentShield
python -m venv .venv-agentdojo
# Windows PowerShell
.\.venv-agentdojo\Scripts\Activate.ps1
python -m pip install -r research_results/requirements-research.txt

These are setup instructions, not an independently tested clean installation. Model API access and configuration are required for benchmark execution.
