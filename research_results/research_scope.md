# Research Question

Can human-defined declarative security policies reduce
indirect prompt injection attack success in autonomous
AI agents while preserving legitimate task completion,
compared with instruction-based and existing defenses?

## Research Scope

- Indirect prompt injection attacks
- Human-defined runtime security policies
- AgentDojo benchmark
- Security and utility trade-offs
- Human approval mechanisms

## Hypothesis

Runtime policy enforcement can improve security while
preserving legitimate task utility.

This hypothesis remains subject to experimental validation.
